Pantheon 0.2.5 introduces the new name and reaching-hands app logo throughout the Windows app and installer.

- Pantheon branding replaces the previous name in the app, settings, window title, documentation, and package names.
- The refined monochrome hand logo appears in the app, Windows taskbar, shortcuts, installer, and browser preview.
- Existing projects, conversations, wallpaper, theme, zoom, and sidebar preferences carry over. The installer retains upgrade registration and migrates matching old shortcuts to Pantheon.
- Attachments, wallpaper-derived colours, local dictation, and the existing signed update system remain available.

Download `Pantheon_0.2.5_x64-setup.exe` for Windows x64, or open Settings > Updates in an existing installation. The complete installer includes the speech model, CPU runtime, and required Windows runtime libraries.

The repository URL and technical app-data identity retain their original names for update and data compatibility. Windows may cache the previous taskbar pin; re-pin Pantheon if its old icon remains.
