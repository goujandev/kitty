# Kitty 0.1.2

This release makes Kitty clearer while it works and more comfortable to read.

- Live working timer and current activity, with clear approval, stopped, and failed states.
- Completed activity folds into an expandable history, keeping the final answer visible.
- Refreshed tabs, sidebar, project lists, and navigation with more generous spacing.
- Larger conversation text, improved paragraph spacing, and softer charcoal surfaces.
- Wallpaper stays on the welcome screen and disappears immediately when you send a prompt.

Existing Kitty 0.1.1 installations can update through **Settings > Updates**. For a first installation, download the Windows x64 setup installer below.
